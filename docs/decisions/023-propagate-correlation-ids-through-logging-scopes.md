# ADR 023: Propagate Correlation IDs Through Logging Scopes

## Status
Accepted

## Context
Distributed systems require traceability across asynchronous operations and service boundaries.

Logs generated by different services must be correlated to track a single business flow.

## Decision
Correlation IDs are propagated through integration events and attached to logging scopes using ILogger.BeginScope().

The Correlation ID:
- Is included in integration event envelopes
- Is propagated across services
- Is added automatically to logs during message processing

## Consequences

### Positive
- Improved observability
- Easier debugging across services
- Better production diagnostics
- Compatible with centralized logging systems

### Negative
- Additional metadata propagation
- Requires discipline across services

## Alternatives considered
- No correlation tracking (rejected due to poor observability)
- Custom logging framework (rejected in favor of standard ILogger)
